# 0.7 完整版本验收

产品要求、实现功能和最终交付声明使用同一张验收表。代码、浏览器和员工发行版均使用独立 0.7 数据区；原服务、设备目录和数据不作为测试数据。

| 路径 | 操作与预期 | 证据 |
| --- | --- | --- |
| 授权目录与召回 | 跨域命中、直达引用、中文问题、不可用来源与预算缺口；私有域不外露 | knowledge / context-recall 行为测试 |
| 真实上下文 | 原生、后台和远程统一网关；实际请求包含相关片段和工作状态，窗口预留与读取预算生效 | 网关测试、真实模型联调 |
| 工作笔记 | 两项工作切换、保存修订、重启恢复、并发保存冲突；宿主事实不变 | work-memory 测试、Harness 界面 |
| 索引与失效 | 重复、乱序、重启、撤权、删除，保留旧版本；只通知订阅者 | resource-lifecycle 测试 |
| 经验发布 | 草稿、验证、独立审核、限定发布、安装、停用；私有来源不能洗白 | experience / market 测试、界面操作 |
| 员工依据页面 | 当前工作选择及清除、历史轮次及返回最新、来源展开/续读/订阅、预算与遗漏、笔记和经验表单 | Electron 功能和截图 |
| 后台依据页面 | 员工/岗位切换、历史轮次、自动刷新保留选择、权限遮蔽、域配置、处理索引 | 浏览器功能和截图 |
| 布局 | 桌面及窄屏、原生 DPI、主次字号、表单标签、长内容换行、错误与空状态 | 独立视觉检查 |
| 发行版 | 打包、首次运行、公司内登录、岗位切换、实际对话和后台同步；安装包无开发设备配置及凭证 | 打包清单、发行版实际启动 |

额外探索场景：快速切换两项工作时不得误保存；写笔记时自动刷新不覆盖输入；来源撤权时界面不给旧缓存正文；停止工作时不得通过新会话绕过执行边界。

验收结果随最终冻结版本补充，不把页面存在等同于功能通过。
