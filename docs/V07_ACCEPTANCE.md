## 实际验收记录（2026-11-16）

- 内核和桌面冻结版本：`8654fbc`；桌面发行文件来自 `bfe7294`，后续差异仅为宿主上下文可见性投影，不涉及桌面文件。`pnpm check`、`pnpm build` 通过。
- 严格冻结 `8654fbc` 的完整行为测试：93 文件、201 项通过；日志 `.local/v07/full-final-8654fbc.log` 留在忽略的验证目录。上下文“受限可见”与“来源过期”区分、checkpoint 撤权竞态、中文 ICU 差异均有正式回归。
- 两路独立只读审查分别检查规范与需求。来源洗白、刷新后遗漏依赖、checkpoint 读取后撤权、停止/恢复代数、重启补发、插件自有分页参数、定时到期及 UI 复验问题均先复现再修复；未以模拟响应替代真实 Harness 验收。
- 本机真实 DeepSeek：重启恢复、两个工作隔离、原决定保留；失效工作笔记通过受限任务从修订 2 重建到 3，旧修订保留。
- Electron 实机：原生 DPI；工作与历史筛选保留；未保存草稿跨自动刷新保持。保存/重新加载后撤权，已打开来源正文自动收起，工作笔记旧正文清除。
- 管理后台：实际来源与预算、域配置、索引处理和用量来自接口。1440 像素布局四列预算；760 像素无页面横向溢出；后台自动刷新保留已选员工、岗位及历史请求。
- 云端真实 DeepSeek Harness SDK：员工账号登录，跨 guides/records 召回两份资料，工作完成至等待人工核对，保存工作笔记到修订 2，后台有实际来源、日志和 provider 用量；访问另一岗位记忆返回 403。累计该阶段 5 次模型请求，输入 20522、输出 1349 tokens，其中包含早期中文分词问题的无匹配分支；修复后新工作正确采用两个来源。
- 完整发行目录首次启动：无项目工作区依赖，在应用内登录云端公司账号、加载本人岗位与独立 INDEX。原生对话读取两份资料并完成回复；新增 3 次网关请求，后台立即同步累计 8 次模型执行及检索记录。
- 经验发布：员工在 Harness 创建个人候选、填写验证说明、提交；管理员在真实后台独立审核并发布；安装后的 Harness 能安装并读取 Skill；另起原生会话后，真实模型通过 skill_index/skill_read 使用该 Skill，按要求给出三项交接检查及未展开资料说明。此流程未改动内核或绕过审核写入公司规则。
- NSIS 安装程序实际安装到独立目录，退出码 0；安装后的程序启动并恢复该测试身份。独立快捷方式、安装 ID、任务栏 ID 与设备命名空间保留旧版。完整发行目录逐文件检查实际模型密钥、后台令牌及员工密码，26761 个文件未发现泄露。
- 独立云服务、数据库、存储卷及 `/v07/` 路径上线；每次部署保存旧版本和该测试数据库备份。原 443、8443 首页、`/a2/` 页面逐字节比对一致。原业务数据及其他容器未修改。

云端验收账号、上传的候选经验、合成资料和运行日志均留在私有测试环境，不进入公共源码或附件。源码导出单独进行凭证及构建完整性检查。

尚未覆盖：另一台物理 Windows 电脑、应用签名、自动更新、生产并发负载和真实企业机器人凭证下的外部收发。当前版本是能实际操作的隔离预览版，不宣称生产验收完成。向量索引与语义选域可通过已有适配接口后续替换。
