# 隔离公司Harness验收清单

所有界面验收均使用本机127.0.0.1:4417、v04-isolated-company、独立原生设备目录。旧服务、旧设备配置及云端不作为写入目标。

| 用户可见要求 | 行为验证与界面状态 | 证据 |
| --- | --- | --- |
| 同一Harness应用内登录 | 登录表单、错误密码、首次接入页、加载/禁用态、成功后岗位页 | 实际Electron窗口与截图 |
| 同一应用进入岗位 | 无第二个Harness桌面EXE；工作区使用原生会话界面 | 进程及同window标识 |
| 岗位切换 | 资料/库存两岗位不同工具、独立INDEX/聊天；返回原岗位保留历史 | 公共生命周期测试、实际原生调用与审计 |
| 工作中心 | 原生侧栏进入；工作/通知/提醒/接口目录、完整结果及人工核对 | 插件注册与实机操作 |
| 会话生命周期 | 退出再登录、软件重启、故障重试；切换中不并发改变身份 | 公共接口测试与实机 |
| 隔离与复用 | 两个外部业务包替换、版本升级/回退、拒绝未授权工具、旧记忆保留 | 独立业务测试和src摘要 |
| 可读与布局 | 实际窗口及窄窗口；明/暗主题，长内容、错误提示和键盘焦点 | 渲染截图、溢出检查 |

额外场景：旧Host未确认退出不得启动新岗位；未分配岗位拒绝；无权限区块显示局部提示；网络失败保留已有数据/草稿；旧版本与本轮设备目录不交叉。

本文件先记录验收范围，完成项与未覆盖项另在最终验收记录中据实际证据填写，不因存在清单声称通过。
