# 员工体验、渠道资源及私有部署

沿用现有内核，修复用户截图中的技术信息外露和浏览器登录启动路径。模型和插件渠道属于宿主资源，不塞进业务Agent；公司凭证不交给模型。

1. 默认工作卡显示岗位/负责人姓名、中文状态、可阅读的段落。UUID、插件内部名、原始JSON折叠到技术记录；原始结果不改写、不丢弃。安全渲染Markdown，不执行模型输出的HTML/脚本。完整结果与人工核对仍可用。
2. 员工双击公司Agent.exe，登录和任务中心在公司软件窗口内，单岗位自动打开原生Harness；不要求先打开浏览器。沿用已有DPAPI设备身份和隔离目录。已有登录重启复用、失败保持可恢复；缺少WebView2需明确提示，不静默退回浏览器。
3. 后台管理服务端渠道资源：显示名称、用途/协议、地址、账号组、启停、并发、凭证状态和说明。密钥写入后不可读回，加密保存，日志与员工目录不含公司凭证。公司、部门、个人可见范围由认证判断。
4. 模型路由实际使用渠道池。同账号多Key合计并发；不同账号/渠道按现有额度调度。处理429/401等明确拒绝后可切换；结果不确定不自动重放。记录渠道、员工、Agent用量；宿主运行并发、个人请求和提供商并发分别限制，不承诺没有排队。现有环境Key作为兼容默认源；新渠道通过后台添加。
5. 插件连接引用动态资源，保留已有连接配置兼容；提供可访问的接口说明/协议目录。具体生图、视频平台需要对应插件适配和真实凭证，不伪称仅保存URL就完成接入。个人本机密钥作为后续可选运行模式，不能假称离线电脑能执行云端后台任务。
6. 提供单机私有部署配置、预检和数据/备份路径说明；HTTPS内网入口、数据库及状态本地持久化。未提供公司主机时不伪称已在内网部署。外部模型调用仍会发送授权上下文；全离线需要本地模型端点及算力。

验收：公共接口失败→通过；安全/租户/并发/明确拒绝切换/未知不重放；员工结果与原文折叠、软件内登录/重启；现有回归与真实Harness；仅更新已有独立测试服务，保留线上与旧发行。
