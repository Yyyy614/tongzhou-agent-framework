# 管理后台验收范围

本轮要求：管理员工、Agent、插件挂载配置、独立记忆、日志和用量；全部连接现有内核。业务系统与通讯平台不在本轮实接范围。

浏览器操作验收清单（实现后逐项验证）：

- 登录：一次性入口、正常进入、退出、过期/非法入口、员工身份无法管理。
- 工作空间：真实统计、图表、最近运行、快捷入口和刷新；未接入渠道明确标记。
- 员工：新增、编辑、部门筛选和搜索、工具授权、停用/恢复；保留当前管理员；并发版本冲突。
- Agent：创建、职责配置、绑定负责人、插件配置、查看挂载、工具验证和结果；停用、恢复；不转移私有记忆。
- 插件：目录、搜索、本地安装、配置校验、初始化健康验证、挂载、额外挂载移除、启停完整循环。
- 记忆：切换 Agent、索引列表、新笔记、版本保存、Markdown 预览、双链引用、重新读取；冲突时保留草稿，切换未保存笔记有明确处理。
- 日志：真实事件、Agent/类型/文本筛选、详情、最新/更早分页状态。
- 用量：真实汇总、每日趋势、员工归属、7/30/90 日和岗位/员工筛选、单请求详情；费用未配置、缺失用量不伪报为零。
- 交互：弹窗关闭/取消/Esc、键盘焦点、必填与错误状态、按钮执行中状态。
- 视觉：1440 桌面、390 手机；总览、列表、配置弹窗、记忆编辑、空状态、错误状态；无页面横向溢出、遮挡和控制台异常。

模型付费任务入口提供明确确认；浏览器验收默认使用不消耗模型的插件验证。真实 Harness 与模型链路由内核集成和既有真实 smoke 独立验证。

所有测试使用通用验证人员和插件，不把公司业务逻辑写入内核。测试产生的人员/Agent 会标明验证用途并停用，历史日志保留。

## 2026-11-12 验收结果

上述主路径已通过真实 Chrome 操作验证；桌面 1440×1000、手机 390×844 均无页面横向溢出，手机弹窗宽 356，导航和 Esc 关闭有效。员工与 Agent、插件启停均验证完整往返，并将验证对象最终停用。

另外完成的异常检查：非法 JSON 保留弹窗输入；记忆并发版本冲突保留草稿；保存中锁定输入；重新读取同一笔记后，旧保存回调不覆盖新草稿；快速切换筛选时旧响应不覆盖新选择；模拟回执丢失后，原弹窗重试使用相同幂等键。付费任务的网络边界使用浏览器拦截夹具验证，未调用真实模型。

员工身份登录后台显示无权限，管理接口返回 403。后台退出后显示登录页。最终完整回归为 26 个测试文件、27 项测试通过，类型检查和构建成功。
