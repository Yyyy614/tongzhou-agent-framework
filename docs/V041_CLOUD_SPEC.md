# 公司 Harness 云端测试发行 0.4.1

用户授权：把公司版 Harness 接到原隔离测试服务器，做员工安装包，另一台 Windows 电脑直接用账号取得岗位、插件、私有记忆；后台看到日志和用量。原数据和生产业务保留。

- 现有云端测试内核与本地关键产物摘要一致，不升级、不重启它；复用已验证的 HTTPS 8443、身份和权限接口。
- 在原隔离测试环境中新增专用验收员工/岗位/审查过的插件，原员工、岗位、记忆和历史内容不改写。先保存测试数据库与文件备份以及旧记录摘要；原客户端/下载清单不替换。
- 员工包用公开发行配置指定服务器与独立设备命名空间，不含开发路径、密码、设备身份、模型Key、管理令牌或SSH凭证。
- 提供 Windows x64 每用户安装器，安装后快捷方式直接执行公司 Harness。退出/卸载保留员工数据；不运行旧启动器、不要求 Node 或原 Harness 预装。
- 两份干净的设备配置经公网 HTTPS 实测同账号登录、同岗位插件/记忆、不同设备凭证；真实原生模型任务与后台日志/用量回读；撤销其中一台设备不影响另一台，其他员工数据/管理接口拒绝。
- 本轮由开发机模拟两台设备，不将其称作已完成物理第二台电脑实测；本地聊天历史不自动跨机同步，服务端私有记忆与配置由账号获取。
- 内部安装包未作公司代码签名，不启用自动更新；明确记录安装、回退、备份、日志和验证边界。
