# 同舟 0.7 Windows 隔离体验版

包含完整 Harness 运行时，直接在软件内登录、选择岗位、对话和进入工作中心，无需另装 Node 或拉起网页启动器。

## 启动

从 [0.7 Release](https://github.com/Yyyy614/tongzhou-agent-framework/releases/tag/v0.7.0-preview.1) 下载安装向导或便携 ZIP。安装向导按当前 Windows 用户安装；便携包必须完整解压后运行“同舟.exe”。不要只复制 exe。

本次体验包默认连接管理员的独立 0.7 测试服务。公开下载不提供公开账号；公司管理员创建员工、岗位和权限后单独发放账号。模型 API Key、员工密码、设备令牌、数据库和记忆均不在发行包中。

其他部署可修改 `resources/app/company.json` 的 `serverURL`，使用兼容版本的 HTTPS 服务。不要在该文件写秘密。内网私有部署复用相同宿主与数据库规则；模型是否出网由管理员配置的模型渠道决定。

登录后进入岗位。在“工作依据与记忆”选择已有工作，应用到下一回合；查看实际来源、预算和遗漏。在“工作笔记”保存决定及下一步，来源变化后可申请受限重建。在“候选经验”提交验证和审核，在内部市场安装已授权能力。

## 与旧版本隔离

0.7 测试使用独立 NSIS GUID、安装名称、快捷方式、Windows 任务栏身份及 `v07-company-test` 设备命名空间。登录状态还按公司服务地址区分；不升级或删除旧版安装及数据。服务端也使用独立目录、数据库和存储卷。

预览程序尚未签名、自动更新未启用。已验证此电脑上的独立发行目录首次登录、真实服务器连接与 Harness 操作；另一台物理电脑和正式生产负载仍需实际试用，不能用本机验证替代。
