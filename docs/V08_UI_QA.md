# 0.8 界面验收清单

本轮新增入口沿用现有同舟视觉系统。检查范围为新0.8隔离后台及新0.8公司Harness，原安装、原数据和线上保持。

| 主张/入口 | 实际操作与状态 | 视觉证据 |
| --- | --- | --- |
| 登录并切换岗位 | 公司账号登录，打开岗位并进入工作依据 | 默认窗口含OS边框截图 |
| 当前工作与独立笔记 | 明确选择工作；当前修订及决定/阻塞/下一步正确 | 目标工作选中，表单字号层次 |
| 笔记历史 | 打开历史，展开旧修订，返回当前；翻页 | 历史标签明确，不覆盖编辑草稿 |
| 有效笔记归档 | 选择已完成条目、填理由、提交；其他活跃项保留 | 提交后修订和归档记录 |
| 来源集合 | 本轮来源→集合→翻页→授权资源读取→收起 | 目录用名称，ID不主占视线 |
| 后台上下文 | 保持员工/岗位选择，自动更新；展开集合 | 默认视口和小视口 |
| 事件确认 | 选已有工作、新事项或忽略；理由保存 | 模态对话框和处理后状态 |
| 纠正关联 | 选后续工作，记录理由；旧动作不重放 | 判断历史有版本和理由 |
| 接收者进展 | 工作详情按自己的可见范围整理进展 | 状态/授权摘录，无私人笔记 |

额外探索：笔记有未保存草稿时切换历史；来源撤权后打开的目录/正文收起；多个工作切换时不串笔记。默认Electron窗口先检查，再以最小800×620窗口检查溢出、裁切、主次与可读性。功能与视觉检查分别记录，真实模型、传输替身、真实平台分开报告。
